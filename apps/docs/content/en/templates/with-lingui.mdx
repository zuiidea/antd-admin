# with-lingui

`apps/with-lingui` adds multilingual capabilities based on Lingui while keeping the same admin architecture.

## Good Fit

- Products serving multiple regions/languages
- Teams that want standardized translation workflow
- Projects requiring language switch in UI

## Highlights

- Same **`src/api/`** layout as **basic** (shared transport, `API_PREFIX`, `auth/` / `users/` modules)
- Lingui message extraction and compilation flow (`i18n:extract`, `i18n:compile`, `i18n:check`)
- Built-in **en** / **zh** switching with Ant Design locale wiring

Full tree and scripts: [apps/with-lingui/README.md](https://github.com/zuiidea/antd-admin/blob/master/apps/with-lingui/README.md).

## Start Development

```bash
pnpm --filter ./apps/with-lingui dev
```
