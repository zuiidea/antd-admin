# basic

`apps/basic` is a streamlined admin template focused on fast startup and simple extension.

## Good Fit

- Internal tools and dashboards
- Teams that want a full scaffold first and may add i18n later
- Projects comfortable with English as the default UI language

## Highlights

- Modular **`src/api/`** (`defineApi` per domain, shared **`API_PREFIX`**, Zod at boundaries)
- Clean route organization and reusable CRUD hooks
- MSW mocks aligned with the same path constants as the API modules
- **`AGENTS.md`** and **`.agents/skills/add-resource/`** for AI-assisted scaffolding

Full tree and scripts: [apps/basic/README.md](https://github.com/zuiidea/antd-admin/blob/master/apps/basic/README.md).

## Start Development

```bash
pnpm --filter ./apps/basic dev
```
