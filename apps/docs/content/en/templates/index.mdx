# Templates

This repository provides two templates:

- **[basic](/en/templates/basic)**: Full admin template; UI copy as plain strings (default English).
- **[with-lingui](/en/templates/with-lingui)**: Same stack plus Lingui i18n (`en` + `zh`) and locale switching.

## How to Choose

- Choose **basic** for the default stack without a bundled i18n workflow (you can add i18n later).
- Choose **with-lingui** when you want Lingui catalogs and bilingual UI from day one.
