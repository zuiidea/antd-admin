# Supported Features

The templates include:

- User login and permission-based routing
- Dashboard and reusable business pages
- Modular API layer (`defineApi`, Zod schemas, shared `API_PREFIX`) and dev proxy / MSW
- Theme and layout customization
- Mock data support with MSW
- Unit tests and E2E tests

Feature details may vary slightly between `basic` and `with-lingui`.
